## ～際に・～際は

動詞  際に は
名詞 の     

に -> 动作进行时点


| x     | 時   | 際            | 場合                 |
|-------|-----|--------------|--------------------|
| 接续    | 普通形 | 动词普通形 / 名词 の | 普通形                | 
| 时间点   | O   | O / 长期间 X    | O  / 长期间 X ，过去时点 X |
| 身分 立场 | X   | X            | O                  |
 
火事の 『  時 OK  /  際 OK  /  場合  OK  』は、エレベーターを使わないでください。

子供の 『  時 OK  /  際 NO /  場合 NO  』 よくこの川で遊びました。

子供の 『  時 NO  /  際 NO /  場合 OK  』 入場料は無料です。

これは京都に行った 『  時 OK   /  際 OK  /  場合 X  』 に撮った写真です。

## 例文

- 火事の際はエレベーターを使わないで、階段を使って避難してください。
- 火灾时不要使用电梯，请使用楼梯避难。 
- 出張の際に旧友の三浦君のうちを{訪ねる|たずねる}つもりだ。
- 我打算出差时去拜访老朋友三浦的家。
- {降りる|おりる}際は足元にご注意ください。
- 下车时请注意脚边。 
- これは台湾を旅行した際に撮った写真です。
- 这是在台湾旅行时所拍的照片。
