## ～について

名詞 + について（は）／名詞 + についての + 名詞

关于~；就~；对于

A をテーマ・内容として（話す、調べる、考える）

用法说明：表示谈论、思考、调查的"内容、主题"，后面多接「話す」「聞く」「調べる」「考える」「書く」「説明する」「発表する」等与语言、信息活动有关的动词。修饰名词时用「についての」。郑重场合（对客户、致辞）用「につきまして」，更书面的近义表达是「に関して」。

区別注意：~に対して 强调动作、态度指向的"对象"（对~），について 强调谈论的"内容"（关于~）。例：先生に対して質問する（向老师提问）／日本の文化について質問する（就日本文化提问）。

- 安全性についての実験ダータが不足している。
- 詳細につきましては、のちほどご説明します。

## 例文

- 日本の歴史について勉強しています。
- 我在学习日本历史方面的知识。
- 新しい製品について、詳しく説明していただけますか。
- 能请您就新产品做个详细说明吗？
- 事故の原因について、警察が調べている。
- 警察正在调查事故的原因。
- この問題についてどう思いますか。
- 关于这个问题你怎么看？
- 留学についての資料を集めているところです。
- 我正在收集关于留学的资料。
